1. Overview

TaskLite is a small Express + TypeScript + Prisma/SQLite backend with a React + TypeScript + Vite frontend. The capstone exercise was to build a feature — Automated Documentation Sync — entirely through GitHub Copilot Agent Mode, driven by explicit Copilot customization (instructions, skills, prompts) rather than ad-hoc chat requests, and to run every change through the full Agentic SDLC: requirements → architecture → design review → implementation plan → implementation → review → verify → PR.

The result is a dependency-free Node.js tool (npm run docs:sync) that regenerates docs/API.md, the README's API table, and CHANGELOG.md directly from the backend's routes, controllers, and Zod validators — so documentation can never silently drift from the code.

4. How Automated Documentation Sync Works

app.ts mounts→ routes/*.routes.ts→ controllers/*.controller.ts→ validators/*.validators.ts→ endpoint model→ docs/API.md + README table + CHANGELOG.md

Run with npm run docs:sync from the repo root. It is pure static text parsing over Node.js built-ins — no new npm dependencies, no database connection, no dynamic import()/execution of backend code. Each controller function's leading // comment is the description shown in the docs; each route's Zod validator is introspected for its request-body field list; response statuses are read from res.status(n)/HttpError(n, msg) calls (plus implicit 200 for a bare res.json(...)).

Changes are snapshot-diffed (docs/.docs-sync-snapshot.json) so re-running with no source changes is fully idempotent, and the README's API table is patched in place between <!-- docs-sync:api-table:start/end --> markers so hand-written prose elsewhere is untouched.

7. Known Limitations

  • Trigger is manual only (npm run docs:sync) — CI enforcement of doc staleness was explicitly deferred.
  • Parser is static-text based, tailored to this repo's current route/controller/validator shape (one route registration per statement, flat z.object({...}) schemas).
  • Frontend components and non-HTTP internals are not documented by this tool.
  • No OpenAPI/Swagger output — Markdown only.
  • The changelog snapshot tracks {method, path, description, requestFields} only, so response-list-only changes don't produce a changelog entry.
